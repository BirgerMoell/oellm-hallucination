# Paper: Teaching a Multilingual 9B Model What It Does Not Know

Draft paper on natural-question hallucination and on-policy preference data in ten European languages.

- `main.tex`: the paper; `references.bib`: bibliography; `figures/fig1.png`: Figure 1 (drawn with `benchmark/plot.py`).
- `main.pdf`: the compiled draft.

Build: `tectonic main.tex` (or `latexmk -pdf main.tex`).

Status: results on the RL-trained merge and the SFT warm-start round are still to be added (marked in red in the PDF).
